# Incremental Forming Automation (Graduate Research)

Bachelor's graduation research at Sophia University (FY2025): **Development of a CAM System for Incremental Forming of CFRTP from 3D CAD Data**. Python code that turns 3D CAD (STL) data into tool paths / G-code for single-point incremental forming of carbon-fiber-reinforced thermoplastic sheets.

## Folders
| Folder / file | What's in it |
|---|---|
| `Python code for CAM system.ipynb` | Original notebook uploaded to this repo. |
| `Python code/` | CAM system notebook and scripts, `Code files/` (earlier script versions, TSP tool-path experiments), test STLs, generated point/tool-path data (`Gchord*.txt`, `toolpath.csv`, `layer.csv`, `dots.csv`). |
| `Test Pieces designs 'stls'/` | CAD models of the test pieces and molds (STL, Creo `.prt`, STEP/IGES). |
| `Graduation Thesis/` | Thesis drafts, final thesis, abstract, chapters, final presentation, figures, and my final code (`my code/`). |
| `Interum reports/` | Interim report and presentations. |
| `Weekly progress reports/` | Weekly progress reports with figures (Oct 2024 – Jul 2025). |
| `Picture2.png` | Figure. |

Not included: files over 50 MB (large point cloud, some large STL molds, a code archive), CAD temp/log files, the virtual environment, and third-party material (senior students' code and papers, translated documents).
